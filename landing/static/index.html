Customs House

MCP approval has no expiry — until now.

You approved that MCP server last week. Who tells you when its tool descriptions change tonight?

The problem

MCP tool descriptions are instructions. Your agent trusts them by design. Approval happens once and never expires. A server you reviewed can silently ship a new description that tells your agent to read .env and pass the contents along as a parameter.

The mechanism

  • Pin — SHA-256 seal over every tool manifest at approval.
  • Verify — re-hash on every session. Match, traffic passes.
  • Quarantine — drift withheld; word-level diff for re-approval.

No model in the trust path. Fail closed everywhere.
