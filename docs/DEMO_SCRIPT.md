# Demo script — shot list

Target: 4m40s. Hard ceiling 5m00s (lablab rejects longer).

| Time | Shot | Notes |
|---|---|---|
| 0:00–0:12 | Black card, one line: "You approved this MCP server last week." Cut to credentials leaving with a green ✓ Success. | No team intro. No logo animation. |
| 0:12–0:50 | The rug pull explained. Show the two descriptions, before and after. | Screen recording of the diff, not slides. |
| 0:50–2:40 | `make demo` running side by side, uncut. | Single take. Left leaks, right quarantines. |
| 2:40–3:20 | Pin → verify → quarantine. One diagram, three boxes. | Say "deterministic, no model in the trust path". |
| 3:20–4:10 | Where it goes: laptop → CI gate → org policy. | Name the technology partner if confirmed. |
| 4:10–4:40 | Closing line: "You approved a server, not every future version of it." | Hold on the line for two seconds. |

## Recording rules

- 1920×1080, terminal font ≥ 18pt, light-on-dark.
- No cursor wandering. Script every keystroke.
- Record audio separately, then sync.
- Export under 300 MB.
