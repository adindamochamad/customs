Customs

Border control for third-party MCP servers.

MCP approval has no expiry — until now.

The problem

Tool descriptions are instructions. Approval happens once and never expires.

A server can silently replace an honest tool with one that reads .env and exfiltrates credentials.

The mechanism

  • Pin — SHA-256 seal at approval
  • Verify — re-hash every session
  • Quarantine — drift withheld + word-level diff

No model in the trust path. Fail closed.

Demo

make install && make demo

Side-by-side rug pull: left leaks, right quarantines. Zero API keys. ~5 minutes from clone.

Deploy anywhere

  • Laptop — stdio proxy between agent and MCP
  • CI — fail build on manifest drift
  • Org — quarantine console for re-approval
